# Скриншоты для слайда 6 и раздела E приложения

| Файл | Что показывает | Куда |
|-|-|-|
| `tests.png` | `run_tests.py`: 18 тестов из 18 | слайд 6, приложение B.3 / E |
| `md5.png` | `md5sum -c MD5SUMS`: исходные данные не менялись | приложение E |
| `demo.png` | `demo.py`: сквозной сценарий (QR → оплата → повтор → отказ → подделка → таймаут → отмена → отчёт → аудит) | приложение E, при желании слайд 6 |

Картинки — настоящий вывод команд, отрисованный в виде окна терминала скриптом `make_screenshots.py`
(не нарисованный вручную). Если жюри или команда хотят «живой» скриншот, те же команды можно запустить
в своём терминале; выводы совпадут.

## Вариант под палитру презентации

`SHOT_THEME=rose python3 docs/screenshots/make_screenshots.py tests` рисует тот же вывод на бордовом фоне
(`tests_rose.png`, он используется на слайде 6; исходники слайдов — в `submission/deck/` после влития PR #7).

## Как пересоздать

```bash
export TIPS_HMAC_SECRET=<демо-ключ из README>
python3 docs/screenshots/make_screenshots.py            # tests, md5, demo, commit
python3 docs/screenshots/make_screenshots.py commit     # только указанные
```

Нужны Python 3 и Pillow (`pip install pillow`) и шрифт DejaVu Sans Mono.

## Скриншот последнего коммита (раздел E)

Снимок `commit.png` относится к ветке `team_11_case_3` и показывает её последний коммит на момент запуска, поэтому его нужно пересоздавать,
если после этого в ветку что-то вливали и сдаваться должен свежий коммит.
Когда ветка создана и все PR влиты, выполните `python3 docs/screenshots/make_screenshots.py commit`
из этой ветки, получится `docs/screenshots/commit.png` (хеш, заголовок, автор, дата, имя ветки; email не печатается).

## Живая демонстрация

`python3 prototype/demo.py` в терминале с цветами занимает около 3 секунд и ничего не пишет в репозиторий.
На защите его удобно запускать вместо показа картинок.
