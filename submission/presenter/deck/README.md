# Исходники презентации

`presentation.pdf` в папке выше — собранный из этих файлов PDF (8 слайдов 16:9).
`presentation.pptx` там же — **старая версия** до смены стиля; актуален PDF. Свежий PPTX можно выгрузить
из редактора слайдов (Share → Export), исходники слайдов в `project/` совпадают с тем, что лежит в редакторе.

| Что | Где |
|-|-|
| Слайды (HTML-подмножество редактора, холст 1920×1080) | `project/slides/*.html` |
| Порядок слайдов и шрифты | `project/deck.json` |
| Картинка для слайда 6 (вывод тестов) | `assets/tests_rose.png` |
| Сборка PDF | `build_deck_pdf.py` |

## Пересобрать PDF

```bash
pip install weasyprint
python3 submission/presenter/deck/build_deck_pdf.py presentation.pdf
```

Нужен интернет: шрифты Manrope и Playfair Display берутся с Google Fonts. Заметки докладчика (`<aside>` в каждом
слайде) в PDF не попадают, они остаются в исходниках.

## Стиль

- Палитра: Cinnabar `#EC4C41`, Wewak `#F5A5A0`, Rosewood `#5A0000` плюс производные тона для больших поверхностей
  (светлая розовая бумага `#FBEDEA`, карточки `#FFF8F6` и `#F6CFCB`, текст `#1F0A0A`, рамка `#2E0000`).
- Один крупный акцентный блок Cinnabar на слайд; Wewak — подписи и числа на тёмных карточках.
- Заголовки: Manrope Light капсом плюс слово прямой антиквой Playfair Display; текст — Manrope.
- Сетка: 12 колонок, промежуток 24, радиус карточек 28.

Тексты на слайдах — черновик: по правилам чемпионата презентатор переписывает их своими словами.
